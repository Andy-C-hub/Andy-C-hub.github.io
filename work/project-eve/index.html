Cybersecurity learning game

The Inside Man — Project e.v.e.

A game based on Season 2 of The Inside Man, built around a series of security-awareness mini-games.

My contribution
Lead Game Developer and Technical Consultant
Tools
Construct 3, CSS and JavaScript

Project e.v.e. title-screen preview.

Project preview.

What I built

I contributed to storyboarding, the visual direction and core game design architecture. The experience puts players into the Khromacom security team, helping protect its e.v.e. product ahead of launch.

How it works

Development included changes to interaction mechanics with accessibility requirements in mind, streamlined activities and shields and rankings to encourage repeat play. These are design decisions rather than a claim of audited WCAG conformance or measured learning gains.

Delivery

HTML5, SCORM 1.2 and SCORM 2004 exports supported delivery through learning management systems.
